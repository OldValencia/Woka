# Ticket Creation

The rules live in the repository, not in this file — `ai/` is the single place project knowledge is
written and read. This skill exists because Claude Code only discovers skills under `.claude/skills/`.

**Read `ai/docs/conventions/tickets.md` now, and follow it.**

Then read the feature file (`<feature>/<feature>.md`) and `tickets/backlog.md`, and the source files
the ticket will touch — a ticket is written against the tree as it is today, never against the plan.
