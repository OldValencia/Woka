Woka Editor — visual spec

The spec for ME-101…ME-129, not a proposal: once this file lands the UI tickets implement it, and a disagreement is settled by changing this file first. Values mirror feature/editor/shell/EditorTokens.kt; colours come from Theme.colors and ViewerChrome and are never re-declared here.

The palette. Accent is #FF9F0A — the same golden as the enabled eye toggle and the active Library dock item, and it replaces the earlier purple everywhere. Wherever it is a ground it carries a dark label: white on it measures 2.06 : 1 and near-black 8.28 : 1. As a glyph on the inspector scrim it measures 6.15 : 1, better than the purple's 3.59. Sliders are white, matching the zoom slider, because the accent marks selection rather than level; switches are green, as in Settings, because a control meaning "on" must not change colour by screen.

On the theme. The editor follows it, like the rest of the app. What does not follow it is the layer sitting on the photograph: ViewerChrome's scrims stay dark and its onScrim* foregrounds stay light in both themes, because legibility over a picture cannot depend on a preference. Flip the switch and watch the top bar, inspector and rail hold still while the overwrite dialog, the conversion sheet and this page change — that difference is the design, not an oversight.

Rail groups are ToolDomain boundaries — Geometry · Color · Annotate · Output — with one 1×20 divider each. Glyphs here stand in for Icons.* and are not part of the spec.

The last item is the disabled state, and it means one specific thing: this tool cannot apply to this file — an HDR output with no encoder for the format, say — dimmed to onScrimDisabled, struck through, and carrying a tooltip that says why. It is not how a tool switched off in Settings looks: that one leaves the rail, the shortcut table and the fold altogether (§3.4), so there is nothing to draw. Redo shows the same disabled treatment in the top bar, and Done is the dirty state — §2 has the clean one.

7 · Save banner — three states
Done closes the editor at once and the save runs behind it, so the banner is the only report. The failure state names the one thing that matters. Success dismisses itself after Motion.BANNER_MS = 2600 ms; the failure state stays until dismissed.

8 · Conversion sheet
Skia writes png, jpg and webp and nothing else, so every other listed format is edited only after a conversion the user agrees to. The Edit button is never a dead button — it either edits or offers this.
