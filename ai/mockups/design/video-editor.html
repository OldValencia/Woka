Woka Video Editor — visual spec

The spec for ai/docs/features/pending/video-editor/, not a proposal: once this file lands the UI tickets implement it, and a disagreement is settled by changing this file first. It is the image editor's shell with one band added — every colour, radius, timing and control here comes from editor.html and EditorTokens.kt unchanged.

The editor draws no top bar. It fills the shell's accessory slots and restores them on dispose: Back (which is cancel) and Revert on the left, the viewer's own pill in the centre with the peek button beside it, undo / redo / Done ▾ on the right, and the window controls after them. That bar is an ordinary themed surface — the editor's buttons read Theme.colors, not the on-scrim set, because they no longer sit on a photograph.

What is new is the band, and it obeys four rules: one picture row · clips are butt-joined and there is never a gap · selection is a clip · splitting is the only way to make a boundary. Bottom-up the stack is rail, band, inspector: the first two are fixed at the bottom edge and the inspector opens above them, so the strip — where the selection lives — never moves when a tool is picked.

Right-click resets. Every control the schema renders — slider, stepper, switch, segmented control, swatch row, pad — returns to its default on a right-click, and right-clicking the inspector's header resets the whole tool. It is the one gesture that works the same on every row, so nothing has to be learned per control type.

Which is why dragging is the left button, on both rows: the body moves, an edge trims. A picture clip dragged by its body reorders; its outer handles and its joins trim. A sound entry behaves identically. The right button is spent on reset, everywhere — two meanings for one button a panel apart is the class of mistake that rule exists to remove.

1 · At rest — no tool selected, one clip
The band reads as the viewer's scrubber, because for every tool other than Trim that is what it is for. 28 dp of film, a play head, a transport and the readout; clicking scrubs. There is no file name in the bar — it left when the editor stopped drawing its own, and the "edited" mark went to the Information panel, which is the thing that already answers what is this file. Done is grey because nothing has been changed yet.

4 · Moving that piece — the others have already slid
A drag never opens a hole and never lets a clip float: the row stays butt-joined, the accent bar is where the clip will land, and the drop is one history entry. There is no x position anybody can get wrong, which is the whole reason there is one row. The dragged clip also carries its own speed badge — a per-clip setting travels with the clip.

6 · The second row, and the entry's own settings
The default is one row with the sound inside it. Detaching, or adding a file, grows a second row that holds both kinds of entry and disappears again when it is emptied — one row, one selection, one waveform renderer. A sound entry answers the same three questions a markup shape does — when it starts, how long it lasts, how it fades — so it takes the same TimeWindow rows, plus a gain and a repeat. The envelope is drawn on the entry, so a fade is visible where the sound is. The right-hand entry is the state only an external file can reach: the file it points at has moved, and everything else still works.
The selected entry has handles, and the drag vocabulary is the picture row's own: the body moves, an edge trims. With the left button — the right one resets a control everywhere in this editor, and two meanings for one button a panel apart is exactly what that rule removes. The panel and the strip are two views of the same numbers: Starts at is what a body-drag writes, the entry's length is what an edge-drag writes.

7 · Markup that appears, holds and fades
A shape drawn on a video gets three more numbers and no new control type — the same TimeWindow rows the sound entry above takes. A shape with no timing is on for the whole video, which is what a still means and what a watermark wants, so the common case never meets this feature. The shape's own span is drawn on the strip, because that is where time is. The canvas shows the caption mid-fade.

8 · The top bar, slot by slot
Nothing here is the editor's own widget: every one of these is a slot in GlobalTopBar that EditorTopBarSetup fills and restores. Revert takes the breadcrumb's slot, which is why the folder path disappears while editing; the pill in the centre is the same lambda the viewer registered, with the carousel eye and Edit retracted as one group so it narrows in a single movement. Left to right: disabled Revert, live Revert, the pill, the peek button, the two undo states, both Done states, and the window controls.

9 · Done ▾ — two entries, or one
The menu is capability-driven. Where the container has a carrier it offers both: the recipe, which is instant and lossless and only visible in Woka, and the render, which is a real file anybody can play. Where it has none — an mkv until its carrier is written — the menu collapses to one entry and the notice says why, before the work rather than after it. Render GIF is the quiet third entry: it appears only when the result is short, and it says what it costs rather than pretending a GIF is the way to a small file.

This render re-encodes

A cut does not land on a keyframe, so the picture is encoded again rather than copied. Copying is lossless and near-instant; encoding is neither.

10 · Banners
The editor closes and the work is reported by StatusPill through StatusBanners, exactly as a photograph's save is — so a render and a save can be up at once without covering each other. A render is the first thing here long enough to need a cancel. The last one is Phase 0's honest state: the foundation opens a video and cannot keep it yet.

What is deliberately not drawn. There is no track list, no transition, no keyframe lane, no layer panel and no render sheet — each of them is refused in video-editor.md §2, and a mockup that showed one would make it arguable. There is also no Cancel button and no file name in the bar: Back is cancel, and the name lives in Information.
