Wallpapers

No Home screen

With one or two linked folders a Home page is a click between you and your files. The linked folders become the sidebar's first section, and the window always shows a folder. That is Finder, Photos and Music — the pattern HIG uses for exactly this shape of app.

No dock

Every dock item finds a place it already has on Windows and macOS: Link at the foot of the sidebar, Search and Settings at the right of the toolbar. The bottom of the window goes back to the content, and the grid stops scrolling under a floating bar.

Pinned is the second section

PinnedSession already exists — a folder deep inside a root plus its scroll position. It finally gets a permanent place: one click from anywhere, with its parent named under it so two “Season 1” rows can be told apart.

The tree replaces breadcrumbs as navigation

Roots expand in place. The toolbar keeps a short path — parent crumbs muted, current folder bold — with Back/Forward beside it. Backspace still goes up.

Two grids, chosen by what is in the folder

Photos: a tight square mosaic, 3 px gaps, no captions — the picture is the label. A folder that is mostly video switches to 16:9 cards with a title, duration and the watched bar, because an episode needs its name. One size slider drives both.

Selection is contextual

The only floating element appears only while something is selected: count, Copy, Move, Duplicate, Delete, Done. Hover a tile for its check circle; Ctrl/Shift-click as in Explorer.

Search lives in the toolbar

Ctrl+F focuses it. Results replace the grid with a scope switch — this folder or all linked folders — and Esc returns to the folder you were in.

First run is one sentence

An empty window says what to do: drop a folder, or Link Folder…. The sidebar's Link row is lit the same blue so both doors are visible. Dropping a folder anywhere on the window links it.

Quick Look on Space

Space over a tile shows it above the grid; arrows move through the folder, Enter opens the full viewer, Space or Esc closes. Video plays muted from where the watch record left it.

Hover a video, see the film

Hovering a video card plays five short excerpts — about 2.5 s each, spread across the runtime — with a stories-style bar on top. No dragging. Leaving the card stops it and shows the poster again.

Info panel, Ctrl+I

A right-hand inspector for the focused file: kind, size, dimensions, dates, camera and exposure for a photo; codec, HDR, frame rate, audio and subtitle tracks for a video. Stays open as focus moves.

The keyboard drives the grid

Arrows move focus, Shift+arrows extend the selection, Enter opens, Space previews, Backspace goes up a level, Ctrl+A selects all, Delete deletes. Try the arrows on this page.

Drop a folder to link it

A folder dragged in from Explorer lights the whole window; dropping links it and selects it in the sidebar. A dropped file opens the viewer, as a double-click from Explorer does today.

Folders update themselves

The open folder is watched on disk: a new screenshot appears in the grid as it is written, a deleted file leaves. Today the grid re-reads only after Woka's own Copy, Move or Delete. Nothing announces the change — one person at one computer moved the file and expects to see it.

Launch restores where you were

The folder that was open when you quit, with its scroll — standard window restoration. Replaces home-rethink's per-card launch flag; without a Home screen there is nothing else to land on.
