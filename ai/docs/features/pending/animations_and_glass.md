# План: Оживление приложения (Анимации и Apple Glass)

Этот документ содержит идеи и концепты для внедрения современного, "живого" дизайна в стиле Apple HIG.

## 1. Apple Glass (Glassmorphism)
- **Динамический фон:** Окно рендерит анимированный Mesh Gradient (2-3 размытых пятна холодных/темных оттенков).
- **Полупрозрачные поверхности:** Заливка панелей (боковое меню, карточки, хедер) полупрозрачным цветом (например, `Color.Black.copy(alpha = 0.5)`).
- **Окантовка и блики:** Рамка 1.dp с градиентом от белого/серого к прозрачному для имитации фаски толстого стекла.
- **Размытие (Frosted Glass):** Применение `Modifier.blur()` или `graphicsLayer` (если поддерживается) для имитации матового стекла над контентом.

## 2. Анимированный Футер / Хедер
- **Футер:** Бесконечная анимация переливания (breathing gradient) с использованием `rememberInfiniteTransition` и плавающими координатами `Brush`.
- **Хедер:** Полупрозрачность, через которую проглядывает скроллящийся контент с размытием.

## 3. Микроинтеракции и "Живой" UI
- **Wiggle-эффект:** Иконки (например, Настройки) при наведении (`PointerEventType.Enter`) слегка поворачиваются туда-сюда (`rotationZ`) с пружинной физикой.
- **Масштаб (Scale Bounce):** При клике/выделении карточки, она пружинисто уменьшается (`scale(0.95f)`) для тактильного отклика.
- **Плавные выпадающие списки (Dropdowns):** Использование `AnimatedVisibility` с `expandVertically() + fadeIn()` для "каплевидного" появления меню.
- **Поиск:** Бесшовный переход (морфинг) от иконки лупы к текстовому полю через `animateContentSize`.

## 4. Комплексные анимации
- **Экспоненциальный скролл/свайп:** Написание кастомного `FlingBehavior` с `exponentialDecay`, чтобы скролл сетки ощущался гладким, как скольжение по льду (сначала быстро, плавно затухает).
- **Каскадное появление (Staggered Grid):** Карточки в сетке при первом открытии папки появляются с задержкой в зависимости от индекса (`delay = index * 30L`), создавая эффект волны.
- **Shared Element Transitions:** Бесшовное расширение картинки из сетки на весь экран при двойном клике (Compose 1.7+).
- **Адаптивный Glow (Тени):** Тень вокруг карточки окрашивается в доминирующий цвет её содержимого.
