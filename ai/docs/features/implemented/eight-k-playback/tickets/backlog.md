# 8K playback: subsequent stages

Integration promoted to [EK-002](EK-002-viewer-integration.md), including real-player validation.

## Broader hardware and memory coverage

Outside the accepted stage: measure weak Windows/NVIDIA hardware, unavailable devices and prolonged
playback. Existing tests do not establish a total RAM/VRAM limit. Broader containers/audio-bearing
8K input and other hardware backends require their own evidence before widening eligibility.
Ordinary films and macOS/Linux retain software playback in this slice.
