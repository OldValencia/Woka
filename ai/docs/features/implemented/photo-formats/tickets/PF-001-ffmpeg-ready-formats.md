# PF-001 — FFmpeg-ready formats, with alpha

| | |
|---|---|
| **Order** | 1 |
| **Depends on** | nothing |
| **Feature** | [Photo formats](../photo-formats.md) |

**Goal.** Open `exr`, `dds`, `xbm`, `xpm`, `pnm` through the bundled FFmpeg, and stop every FFmpeg
still from losing its alpha channel.
**Why now.** Five formats need no new dependency, and alpha has to be fixed before `dds`/`xpm` ship,
or they ship with black where they should be transparent.

## Steps
1. `FfmpegStreamFacts.kt` — `onGrabber` sets `grabber.pixelFormat = AV_PIX_FMT_BGRA` (was `BGR24`).
2. `FfmpegStillDecoder.kt` — `toBgrImage()` becomes `toBgraImage()`: `BufferedImage.TYPE_4BYTE_ABGR`,
   four bytes per pixel, the row copy still honours `imageStride`. The FFmpeg buffer is
   B,G,R,A and `TYPE_4BYTE_ABGR`'s raster is A,B,G,R, so each pixel is reordered while copying, not
   copied row-wise. Update the KDoc that names `BGR24` (ME-182's stride note still applies).
3. `MediaKind.kt` — add `exr`, `dds`, `xbm`, `xpm`, `pnm` to `IMAGE_EXTENSIONS` and
   `COIL_BLIND_EXTENSIONS`.
4. `StillDecoders.kt` — add the same five to `FFMPEG_EXTENSIONS`; update the KDoc's measurement note
   (2026-10-24, FFmpeg 8.1.2).
5. Fixtures: `still.exr`, `still.dds` (DXT5 with an alpha gradient), `still.xbm`, `still.xpm` (with
   a `None` colour), `still.pnm` — each 64×48, generated by ImageMagick 7.1.2, committed under
   `jvmTest/resources/media/`, one row each in its `README.md`.
6. `StillDecoderRoutingTest.kt` — the five extensions → `FfmpegStillDecoder`.
7. New `integration/NewStillFormatsTest.kt` — each fixture decodes to 64×48 through
   `stillDecoderFor`; `still.dds` and `still.xpm` keep a pixel with alpha < 255.
8. `WindowsFileAssociationsTest.kt` — 62 → 67. `desktopApp/build.gradle.kts` — five
   `mediaAssociations` rows (`image/x-exr`, `image/vnd-ms.dds`, `image/x-xbitmap`, `image/x-xpixmap`,
   `image/x-portable-anymap`).
